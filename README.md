# SC HUB

A central landing page for a suite of fan-made **Star Citizen** reference tools. One click takes you to whichever tool you need.

Live site: [seeknd.github.io/sc-hub](https://seeknd.github.io/sc-hub)

---

## The Tools

### Forge — Crafting Calculator
Browse every craftable item in the RediMake Item Fabricator, plan complete sets, track unlocked blueprints, manage work orders, and coordinate material requests with your org. → [seeknd.github.io/Forge](https://seeknd.github.io/Forge)

### Strata — Mining Operations
Find ore locations, decode scanner signals, compare refinery yields, plan multi-stop runs, and track your refined inventory. → [seeknd.github.io/Strata](https://seeknd.github.io/Strata)

### Hardpoint — Ship Loadout Analyser
Per-slot best-weapon picker with effective-DPS-at-range, time-to-kill analysis, vulnerability lists, and side-by-side ship comparison. → [seeknd.github.io/Hardpoint](https://seeknd.github.io/Hardpoint)

### Wikelo — Banu Trade Reference
What Wikelo offers, what he'll trade for, the reputation tracks, and an inventory planner for the materials you'll need. → [seeknd.github.io/Wikelo](https://seeknd.github.io/Wikelo)

---

## Tech

Pure static site — HTML, CSS, vanilla JS. No frameworks, no build tools, no server. Hosted on GitHub Pages.
